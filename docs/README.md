## Conventions

- Un ADR par décision structurante, numéroté et immuable : on en ajoute un nouveau
  pour revenir sur une décision plutôt que de réécrire l'ancien.
- La documentation vit dans le dépôt et évolue avec le code : une PR qui change
  le comportement doit mettre à jour la page concernée.
